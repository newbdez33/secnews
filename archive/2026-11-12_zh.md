1. [ScreenConnect 遭活跃利用，攻击者借被攻陷的 ScreenConnect 环境入侵 MSP，已波及数十家组织](https://www.bleepingcomputer.com/news/security/active-screenconnect-attacks-breach-msps-impact-dozens-of-organizations/) — ConnectWise 正在调查，攻击者会往客户终端装恶意远控客户端。用 MSP 托管或自建 ScreenConnect 的，请检查有没有陌生的远控客户端和会话。

[FortiOS 有 3 个 Critical 漏洞，Fortinet 这次共修了近 100 个](https://www.security-next.com/192635) — 最危险的是 CVE-2026-126259：在 FGSP 加配置同步或自动扩展的配置下，攻击者发一个特制 HA 包，不用认证就能以最高管理员权限执行命令。另外两个是 BGP 守护进程问题（CVE-2026-126254）和未认证发送 OSPF LSA（CVE-2026-126253）。总数见 [SecurityWeek](https://www.securityweek.com/fortinet-patches-nearly-100-vulnerabilities/)。
3. [Apache HTTP Server 2.4.71 修复 mod_http2 堆破坏 RCE（CVE-2026-119618，官方定级 Critical）](https://httpd.apache.org/security/vulnerabilities_24.html) — 影响 2.4.55 到 2.4.70（独立版 mod_h2 是 2.0.8 到 2.0.42），同时修了 mod_md 空指针导致子进程崩溃的问题（Important）。开了 HTTP/2 的服务器请尽快升级。
4. [Red Hat Quay 镜像仓库有两个严重漏洞：CVE-2026-123710（9.8）和 CVE-2026-110697（9.9）](https://github.com/advisories/GHSA-jw94-v4wp-236w) — 前者让未认证客户端拿到自己控制受众的匿名 token，再拿去滥用 service key 轮换接口；后者是 robot 账户列表里的 SQL LIKE 注入（[GHSA](https://github.com/advisories/GHSA-cxc6-5mg7-78wq)）。自建 Quay 的请升级。
5. 🔴 [Node.js 22 / 24 / 26 发布安全更新，修复多个 High 漏洞](https://nodejs.org/en/blog/vulnerability/november-2026-security-releases) — 最值得注意的是 CVE-2026-123864：HTTPS 服务在特定写法下会把其他连接的堆内存回显给攻击者，可能包含 TLS 私钥，三条版本线都受影响。另外 HTTP/2 服务可被未认证客户端直接打崩（CVE-2026-123863），或者被拖着泄漏内存和文件描述符（CVE-2026-123865），还有一个释放后重用会泄漏响应内容（CVE-2026-123866）。请升级到 22.23.5、24.22.3 或 26.13.1。
