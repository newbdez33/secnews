[Check Point 网关遭 PHP2Shell + 零日提权 CVE-2026-123039 在野攻击，攻击者再横移到 ESXi 投放擦除器](https://www.securityweek.com/php2shell-exploited-in-destructive-check-point-gateway-attacks/) — 自 10 月 30 日起，攻击者先用 PHP2Shell（CVE-2026-109618/109619）打 Mobile Access 门户，再用 Gaia OS DynamicCLI 缺失授权漏洞（CVSS 7.8）提权到 root，植入 TSGA 后门，并经 SSH 横移到 VMware ESXi 投放 destroy_v6 擦除器。Check Point 已发紧急热修复，CISA 已列入 KEV（期限 11/16）（[BleepingComputer](https://www.bleepingcomputer.com/news/security/check-point-patches-zero-day-that-lets-hackers-get-root-access/)）。用 R81–R82.20 的请立即打热修复并排查 Web Shell。
2. [CISA 将 UnrealIRCd CVE-2026-114713 列入 KEV，确认在野利用](https://www.cisa.gov/known-exploited-vulnerabilities-catalog) — 11/9 已报的 IRCv3 标签转义缺陷：多服务器互联网络中，任意用户都能注入服务器间命令。修复版 6.2.7.1 已发布，KEV 期限 11/16。
3. [FortiMail 公开 8 个 Critical 漏洞，其中 3 个 CVSS 9.8 可免认证执行代码](https://fortiguard.fortinet.com/psirt/FG-IR-26-199) — 包括路径穿越 CVE-2026-126147、命令注入 CVE-2026-126148、SQL 注入 CVE-2026-126263，另有 CVE-2026-126164（9.4）等。Fortinet 表示 10 月的更新已修复大部分，目前未见利用（[Security NEXT](https://www.security-next.com/192797)）。
4. 🔴 [Linux 内核 KSMBD 的 SMB Direct 整数下溢可致远程代码执行（ZDI-26-998，CVSS 9.0）](http://www.zerodayinitiative.com/advisories/ZDI-26-998/) — 只影响启用了 SMB Direct 的 ksmbd 内核 SMB 服务器。ZDI 同批还公开了 BPF、SCTP、Qdisc、pagemap 等 8 个内核本地提权漏洞。
5. [SmarterMail 认证绕过 CVE-2026-126969（CVSS 9.1）](http://www.zerodayinitiative.com/advisories/ZDI-26-997/) — 令牌熵不足，未认证攻击者即可绕过登录。同批还有文件编辑 API 目录穿越 RCE 等 3 个漏洞，自建 SmarterMail 的请升级。
6. 🔴 [FrankenPHP 官方 Docker 镜像长期没跟上基础镜像的安全修复（CVE-2026-128027，CVSS 9.8）](https://nvd.nist.gov/vuln/detail/CVE-2026-128027) — 1.1.11 之前的镜像只在新基础镜像标签出现时才重建，Alpine、PHP、Go 的安全修复没有进镜像。同时公布的还有静态二进制捆绑的 brotli 扩展漏洞（CVE-2026-128014）和认证绕过（CVE-2026-128023）。用 FrankenPHP 镜像的请重新拉取最新版。
7. 🔴 [Windows 远程桌面连接客户端存在链接跟随 RCE（CVE-2026-119824，ZDI-26-967）](http://www.zerodayinitiative.com/advisories/ZDI-26-967/) — 用户连上恶意 RDP 服务器就可能被执行代码。别连接不可信的 RDP 服务器，并确认已装好最新更新。
8. [Dropbear SSH 对 unix socket 转发不检查 permitopen/permitlisten，受限密钥可直连 docker.sock](https://seclists.org/oss-sec/2026/q4/690) — 研究者公开了 PoC，目前还没有修复。按 authorized_keys 限制转发目标的 CI/备份密钥，可借此访问 Docker 或数据库 socket，最高可达宿主机 root（自评 CVSS 9.9）。在官方修复前，请对受限密钥加上 no-port-forwarding。
